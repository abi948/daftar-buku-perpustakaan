APLIKASI DAFTAR BUKU PERPUSTAKAAN

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder daftar-buku-perpustakaan di VS Code.
3. Buka terminal pada folder tersebut.
4. Jalankan: npm install
5. Setelah selesai, jalankan: npm run dev
6. Buka alamat yang muncul, biasanya http://localhost:5173

Project ini menggunakan React dan Vite.
